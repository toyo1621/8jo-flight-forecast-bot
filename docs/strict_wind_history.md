# 風条件を統一した実績選定

同じ便の確定ステータスを持つ実績から、風向差20度以内・平均風速差3m/s以内・最大瞬間風速差5m/s以内をANDで選ぶ。
角度は北をまたぐ最短差。境界を含み、欠測・bool・非有限値・負数は使わない。
旧tuple形式の実績には突風情報がないため推測せず除外する。本番の読取は詳細辞書を使う。
5件未満でも条件は拡大しない。計算には全候補、詳細には風向差→平均風速差→瞬間風速差→日付降順の最大10件を使う。
降水・視程・雲・南風・台風などの係数は変更しない。旧公開記録は変更しない。
