# 過去の予測と運航結果

- 一覧は新しい日付順。各日に対象3便の保存スコアと結果を表示。
- 運航は緑、欠航・引き返しはオレンジ、未取得はグレー。文字でも状態を区別。
- 引き返しは欠航件数に重複計上しない。未取得は確認済み件数から除外。
- 月と結果条件はAND。集計は表示中の日付だけが対象。JS無効でも全件と初期集計は読める。
- 気象詳細は保存済みJMA入力を表示し、現在の予報や係数で過去値を再計算しない。
- 収集テーブルの気象は観測と確認できないため、実測天気と呼ばない。欠測は記録なし。
- 適用係数は保存内訳のみを表示。保存内訳にある履歴全件等は公開HTMLへ展開しない。
- DB変更なし。既存の公開確認済み・legacyの選別条件は維持する。

検証: test_history_usability.py、既存静的生成テスト。
ブラウザで360px/1280px幅、月変更、欠航・未取得条件、空状態、詳細開閉を確認。
プレビューfixtureは架空のスコア・気象を含むテスト用。実運航評価には使用しない。
